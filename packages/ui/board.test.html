One file holds every value

This is the design language of the Notebench prototype, rebuilt so that nothing is hardcoded. Floating rounded panels sit on a neutral ground, controls are pills, and wells are cut into the panels. Every color, size, radius, shadow, z-index and duration comes from tokens.json.

Live example. Type in the text, or use the buttons. The rail on the left shows who last touched the part.

Principles

Five rules decide every choice below. A new component that breaks one should change.

The file is the system

A value that is not in tokens.json does not exist. Components use variables, and a lint step fails the build on a literal.

Panels float, wells sink

Panels are raised rounded sheets on the ground. Inside them, wells are recessed. Depth comes from color steps, not shadows. Only menus, dialogs and the composer float.

Every part shows who wrote it

A rail, an icon and a label say AI draft, your edit, locked or source changed. Color is never the only signal.

Yellow means a source

Citations and search matches are the only yellow in the product. Tool colors appear on icons only, always next to a label.

Curves are a scale, not a mood

Six radius steps, each with one job. Nested corners follow one rule, so a child never looks looser than its parent.

Color

Names start with --nb- and then say the role. The same names exist in light and dark, so a component never knows which theme it is in.

Naming rule

--nb-ground and --nb-marker-wash are roles. --background and --yellow-200 describe a look or a place, so they break the first time the theme changes. Variants always come last: -hover, -active, -wash, -text, -2, -3.

Shape, depth and motion

Curves follow a stepped scale, the way Claude's own interface does: small radii for tags, medium for inputs and wells, large for cards, and the largest for panels, dialogs and the composer. Anthropic does not publish its radii, so the steps are chosen to match the prototype's 22 and 16, not copied.

Nested corners

When a rounded child sits a distance p inside a rounded parent, the child's radius is the parent's radius minus p, and never less than radius-xs. This keeps the gap between the two curves even.

Elevation

Panels and cards use a hairline border and no shadow. Only things that float get one: the composer and menus use shadow-float, dialogs use shadow-modal.

Provenance

Each part of an output (a slide, a paragraph, an audio line) is in exactly one of four states. The state shows three ways at once: the rail pattern, an icon and a text label.

StateRailIcon and labelMeaning
AI draft dashedDrafted by AIA model wrote this and you have not changed it.
Your edit solidEdited by youYou changed it. Regeneration keeps your wording unless you ask otherwise.
Locked doubleLockedNothing can change it, including later regeneration, until you unlock it.
Source changed dottedSource changedA source behind this part was refreshed. Review it before you export.

The rail is a rounded bar inset from the card edge, so it follows the curve instead of fighting it. Dashed and dotted rails belong to parts only. Fields, banners and cards never use them.

Accessibility

The target is WCAG 2.1 AA. The contrast numbers below are computed from tokens.json on every build, so a token change that breaks a pair fails the build instead of shipping.

Contrast

Text is 4.5 to 1 or better on every surface it sits on. Control borders, focus rings, rails, hatch, chart series and tool icons are 3 to 1 or better.

Color is never alone

Status pairs color with an icon and words. Provenance adds a rail pattern. Charts label every series directly and stay apart for color-blind readers.

Focus

One rule for everything: a 2px ring in --nb-focus with a 2px gap.

Targets

Controls are 36px, or 44px on touch. Inline chips and citations are 24px with space around them.

Keyboard and screen readers

Every action works from the keyboard. Reordering uses buttons, not only dragging. Live regions announce results. Dialogs are native and trap focus.

Motion, zoom, contrast modes

Reduced motion zeroes every duration. The layout reflows at 320px with no sideways scrolling. In forced-colors mode the system colors win and the labels still carry meaning.

Handoff

Edit tokens.json, run one command, and every output updates. Nothing is typed twice.

Where each value lives

FileWho edits it
tokens.jsonYou. The only source.
tokens.cssGenerated. CSS variables and both themes.
tokens.media.cssGenerated. Breakpoints as custom media.
tokens.tsGenerated. Names and numbers for TypeScript.
tailwind.preset.cjsGenerated. Tailwind utilities that can only output tokens.
check_contrast.pyReads the source. Fails on any weak pair.
lint_tokens.pyFails on a literal color, size, radius or duration in CSS.
