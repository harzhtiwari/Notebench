# Notebench Examples

This directory contains runnable, self-contained examples demonstrating how to use Notebench packages and APIs.

## Available Examples

| Example | Description |
|---------|-------------|
| [`basic-usage`](./basic-usage/) | Demonstrates initializing the structured logger, validating slide deck ASTs, and handling schema contracts |

## Running Examples

From the repository root, install dependencies and execute any example:

```bash
# Run basic usage example
pnpm --filter example-basic-usage start
```
