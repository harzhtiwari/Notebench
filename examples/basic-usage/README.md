# Basic Usage Example

This example demonstrates how to integrate and use `@notebench/contracts` and `@notebench/logger` in a TypeScript application.

## What it demonstrates

- Initializing the structured logger from `@notebench/logger`
- Building and validating a living slide deck AST using `@notebench/contracts` schemas
- Handling validation results and structured log output

## Running this example

```bash
pnpm start
```
